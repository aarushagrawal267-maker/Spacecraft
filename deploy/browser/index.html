Heliograph

Spacecraft telemetry anomaly detection · NASA SMAP & MSL (Curiosity)

Browser demo — the full app runs locally. This page is a viewer of the stored reference results: seven detection methods run on all 81 channels of the SMAP/MSL benchmark. Nothing is trained or computed here. Training, live inference, the telemetry replay and the model laboratory are part of the full app (source and setup).

Benchmark results

Event-wise scores count each expert-labelled anomaly sequence once: a label is found when a detected interval overlaps it, and a detected interval that overlaps no label is a false alarm. F0.5 weights precision more than recall, as in Hundman et al. (fewer false alarms for operators). Point-wise F1 scores every timestep. Mean AP is the average precision of the anomaly scores, averaged over channels.

      About this demo

      • The model outputs, thresholds, detected intervals and metrics are the stored reference results in the repository's reference/ folder, produced by the full app (LSTM: standard profile, 64 units, at most 20 epochs, on CPU). Labels are the official Telemanom expert labels (channel P-2 has two overlapping rows, which are merged).
      • The telemetry is not stored with this page. When you open a channel, its test stream is downloaded from the public GitHub copy of the benchmark (TranAD repository, pinned commit), the same source the full app's setup uses. Telemetry values are the benchmark's pre-scaled values.
      • Independent research implementation inspired by Hundman et al., Detecting Spacecraft Anomalies Using LSTMs and Nonparametric Dynamic Thresholding (KDD 2018). Not affiliated with NASA, JPL or Caltech. A detected anomaly is an unusual pattern that warrants investigation, not proof of a hardware failure.
